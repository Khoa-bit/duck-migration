#duck-migration

duck-migration is a lightweight Go library for handling database migrations, inspired by Goose. It supports both the craw/sqlite and built-in database/sql interfaces, making it easy to manage schema migrations across different SQLite drivers. The library currently only supports up migrations.

Features

Compatible with both craw/sqlite and database/sql interfaces.

Supports up migrations from an embedded file system.

Simple and lightweight API.
